# 아빠랑 나랑 — 출시 홍보안 및 측정 기준

상태: 기획 완료, 집행 보류. Apple 승인 및 실제 스토어 공개 확인 뒤 대표 승인으로 시작한다.

## 메시지

약속 하나, 함께 쌓는 하루. 부모와 아이가 오늘 한 칸을 채우는 가족 약속 앱.

핵심 고객은 운동·독서·생활 약속을 아이와 이어가고 싶은 부모다. 아빠와 아이가 출발점이지만 다양한 보호자가 사용할 수 있음을 설명한다. “습관이 반드시 생긴다”, 건강 개선이나 교육 성과를 보장하는 표현은 사용하지 않는다.

## 출시 전 준비

- 홈페이지: AP Edu와 메인에서 소개 페이지 연결. 현재 심사 중을 표시하고 다운로드를 가장하지 않는다.
- 소재: 실제 홈·도장판·룰렛 화면 사용. 예시 기록임을 표시한다. 아동 실명·실제 건강 기록을 홍보에 사용하지 않는다.
- 심사: 앱 1.0(1)과 Family Pass 각각 승인 여부 및 실제 판매 상태를 확인한다.
- 가격: 무료 약속 하나, 선택형 Family Pass 한국 4,900원 일회 구매. 구독 없음.
- 승인 이후에만 홈페이지 버튼을 실제 App Store 다운로드 링크로 전환한다.

## 단계별 홍보

1. 첫 7일: 홈페이지와 회사 보유 채널의 소개 콘텐츠. 제품을 이해시키는 짧은 화면 영상 3편과 이미지 3종을 제작한다. 게시는 승인 후.
2. 다음 7일: 첫 이용에서 약속 설정·도장 체크가 이해되는지 실제 사용 피드백을 수집한다. 가족 공유·구매 복원 문의를 별도 분류한다.
3. 유료 홍보: 사용 불편·크래시·리뷰 이슈를 해결하고, 지출 한도와 대상 채널을 승인받은 뒤 소규모 실험. 예산을 임의 집행하지 않는다.

## 소재 초안

- 홈 화면: “아빠랑 나랑. 약속 하나, 함께 쌓는 하루.” / “오늘의 작은 약속을 도장으로 남겨요.”
- 도장판: “거창한 계획 대신, 오늘 한 칸.” / 달리기·영어 책읽기·우리만의 약속을 소개한다.
- 룰렛·편지: “매일의 약속에 작은 재미를.” / 도장판, 응원, 절반에서 열리는 편지를 실제 화면으로 보여준다.
- 15초 영상: 0–3초 함께 정한 약속 → 3–7초 오늘 한 칸 → 7–11초 룰렛·응원 → 11–15초 앱 이름·무료 약속 하나·다운로드. 출시 후 실제 화면으로 제작.

## 트래킹

앱 자체에 분석 SDK나 새로운 개인 데이터 수집을 넣지 않는다. 이미 제출한 개인정보 답변과 일치시킨다.

| 지표 | 근거 | 해석 |
|---|---|---|
| 앱/결제 심사 상태 | ASC 직접 확인, Apple 메일은 보조 | 제출·심사·승인·실제 출시 구분 |
| 첫 다운로드 / 재다운로드 | Apple 보고서 | 웹 클릭을 다운로드로 계산하지 않음 |
| 제품 페이지 조회→다운로드 | ASC Analytics | 집계가 제공되는 날짜·조건만 비교 |
| 채널별 다운로드 | Apple 캠페인 링크 | 홈페이지, 회사 SNS, 광고 토큰 분리 |
| Family Pass 판매 / 수익 | Apple 판매 보고서 | 결제 건수와 수익 분리, 환불 반영 |
| 크래시·리뷰·사용 문의 | ASC 및 지원 문의 | 문제 유형과 해결 버전 기록 |

Apple 캠페인 생성은 앱의 분석 데이터가 생긴 뒤 가능하다. 출시 후 최소 24시간 데이터 상태를 확인하고 공식 UI에서 provider token을 얻는다. 토큰을 임의 생성하지 않는다. 캠페인 지표는 5건 이상 등 Apple 개인정보 보호 기준에 따라 표시되지 않을 수 있다. 미수집·임계치 미달을 0으로 보고하지 않는다.

캠페인 이름: dadandme_ap_home, dadandme_ap_edu, dadandme_company_social, dadandme_paid_test. 홈페이지 소개 링크의 UTM은 이름 구분을 위한 준비다. UTM 자체만으로 방문/다운로드 통계가 수집되는 것은 아니며 현재 별도 웹 방문 수집기는 설치하지 않았다.

공식 근거: https://developer.apple.com/help/app-store-connect-analytics/acquisition/campaign-links

## 운영

기존 4시간 자동 확인에 아빠랑 나랑·Family Pass·실제 스토어 공개 여부를 추가했다. 같은 대기 상태는 반복 알림하지 않는다. 관리자 앱 현황에 앱 ID 6821352092와 제출 ID 57d3ec9f-1f50-4849-b1ec-c73c29d32abf를 기록했다. 보고서 동기화 여부는 출시 후 다시 확인해야 한다.

주간 보고는 확인일·출처·다운로드·조회 전환·패스 판매·수익·사용 문의·다음 조치로 작성한다. 현재 목표 수치는 출시 첫 주 실제 기준선 확보이며, 유료 집행 예산과 성과 기준은 이후 승인한다.
