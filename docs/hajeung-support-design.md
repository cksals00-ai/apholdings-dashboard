# 하자증권 담당자 안내·테스트 신청·수정 요청 페이지

## 승인과 실행 순서
2026-10-27 사용자는 설치·가이드 공개, 회사 이메일 신청 후 관리자 승인, 요청 작성자·관리자만 열람하는 구성을 승인했다. 기존 앱 등록 작업을 먼저 마친 뒤 구현·공개한다. 예정 경로는 https://www.apholdings.kr/hajeung/ 이며 아직 배포된 페이지가 아니다.

## 선택한 구성
기존 apholdings.kr 정적 사이트와 기존 관리자 화면을 확장한다. 별도 외부 설문은 접수와 처리 상태가 분산되고, 전체 회원 전용 안내는 설치 전 접근이 불편하여 채택하지 않는다. 공개 안내와 비공개 접수를 한 경로에서 제공한다.

## 공개 화면
휴대폰 첫 화면에 하자증권 관리대장 소개, iPhone 설치, Android 설치, 테스트 계정 신청, 수정 요청 버튼을 배치한다. 설치 링크는 실제 공개 가능 여부와 마지막 확인 시각을 표시한다. 미출시 Android는 준비 중으로 표시하며 작동하지 않는 스토어 링크를 설치 가능으로 표시하지 않는다.

iPhone은 사용자의 Apple ID로 TestFlight를 설치하고 기존 승인 링크로 참여한다. Apple ID를 발급하거나 비밀번호를 수집하지 않는다. TestFlight 참여와 하자증권 앱 로그인은 별개임을 설명한다.

가이드는 설치 → 개인 앱 계정 로그인 → 가상 자료 조회 → 등록·수정 → 첨부 → 수정 요청의 짧은 단계로 구성한다. 실제 업무 자료·개인정보가 담긴 문서 대신 가상 자료를 사용하도록 안내한다.

## 계정 신청과 발급
회사 이메일, 이름, 소속, 이용 기기만 접수한다. 이메일 소유 확인 후 신청자에게 본인 신청 상태를 보여준다. 도메인만으로 자동 승인하지 않는다. 관리자는 신청을 승인·보류·거절할 수 있고 처리 이력을 남긴다.

승인된 테스트 사용자는 등록·수정 권한과 테스트 자료 범위만 갖는다. 웹 신청 승인과 앱 계정 발급 성공을 별도 상태로 관리한다. 계정·코드는 공개 페이지나 게시글에 노출하지 않으며 기존 심사 계정을 재사용하지 않는다. 개인별 코드 전달은 승인된 개별 채널로 수행하며 발급·전달 오류에는 재시도 가능한 상태를 표시한다. 실제 인증·보안 권한을 생성하는 단계는 별도 실행 시 권한과 전달 방식을 확인한다.

## 수정 요청
신청 시 확인한 이메일로 로그인한 사용자가 제목, 오류/개선/질문 구분, 발생 화면, 내용, 기기·OS·앱 버전, 선택적 사진을 제출한다. 카메라 촬영·사진 선택을 지원하고 사진 미첨부도 허용한다. 접수 번호와 접수·확인 중·처리 중·추가 정보 요청·완료 상태를 제공한다.

작성자와 관리자만 본문·답변·첨부를 볼 수 있다. 목록 조회뿐 아니라 직접 주소·첨부 다운로드에도 서버 권한 검사를 적용한다. 첨부는 비공개 저장소와 짧은 유효기간 링크를 사용하고 공개 버킷을 사용하지 않는다. 파일 형식·용량 제한, 반복 제출 방지, 개인정보 포함 주의 안내를 제공한다. 관리자 상태 변경과 답변 이력을 남긴다. 외부 이메일 알림 발송은 이번 설계 승인만으로 자동 실행하지 않는다.

## 기존 관리자 통합
기존 관리자에 하자증권 지원 메뉴를 추가한다. 미처리 신청·수정 요청 수, 목록 필터, 신청 승인, 담당 처리 상태, 비공개 답변, 마지막 변경 시각을 제공한다. 기존 관리자 전체 권한을 일반 신청자에게 부여하지 않는다. 운영 하자증권 데이터와 웹 접수 데이터를 혼합하지 않는다.

## 유료화 기준
Apple의 승인된 상품 구성·무료/유료 기능·사용 제한·구독 기간·체험·복원·만료 동작을 기준으로 Android를 대조한다. 실제 플랫폼별 상품 가격과 결제 방식이 확인된 내용만 안내한다. 테스트 계정 이용 권한과 실제 유료 결제를 구분한다. 양 플랫폼 구매 권한 공유는 구현·검증 전 약속하지 않는다. 계정 신청 승인만으로 유료 구매나 운영 이용 권한을 생성하지 않는다.

## 구현 전 확인과 보안
기존 사이트는 GitHub Pages 정적 배포이고 관리자는 서버 인증을 사용한다. 구현 계획에서 기존 접수·이메일 확인·발급 기능의 재사용 가능 여부를 확인하고, 없으면 필요한 서버 기능을 명시한다. 비밀 키·앱 코드·운영 문서는 정적 파일에 포함하지 않는다. 개인정보 수집 목적·항목·보관·삭제 안내는 실제 서버 보관 정책과 일치시킨 후 공개한다. 확인되지 않은 자동 삭제 기간을 만들어 기재하지 않는다.

## 완료 기준
- 360px/390px 모바일과 데스크톱에서 설치·신청·사진 첨부·요청 확인 가능.
- 서로 다른 두 신청자가 상대 신청·글·첨부를 조회할 수 없음.
- 비로그인·만료 세션·직접 첨부 주소 접근을 차단함.
- 중복 클릭·네트워크 실패·사진 업로드 실패에 중복 접수나 성공 오표시 없음.
- 승인만 됐지만 계정 발급이 실패한 상태와 정상 발급 상태를 구분함.
- 테스트 자료만 접근 가능하고 운영 자료·실제 결제 권한을 노출하지 않음.
- 실제 배포 URL과 기존 관리자 회귀 검증 후 사용자에게 전달함.
