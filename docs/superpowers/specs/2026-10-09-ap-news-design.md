# AP News Daily — 승인된 서비스 설계

2026-10-09 사용자: 구성 승인 및 진행 요청. 발신 주소 alfred.park@apholdings.kr 확정.

기존 www.apholdings.kr/ko/news/ 및 18개 기사, 6개 언어 페이지를 보존한다. 일일판은 별도 daily 경로로 연결하고 AP News 목록에 최신호·구독 영역을 추가한다. 원본은 site-source/newsletter/issues/*.json 한 곳에 두어 웹·이메일·PDF 내용이 일치한다.

## 편집·디자인
- AP의 기존 ap_mark.png 로고, 아이보리(#f7f4ed), 차콜(#172338), 골드(#9b7950), 세리프 영문 제목, 읽기 편한 한글 본문과 넓은 여백.
- 하루 주요 AI 기사 5~7개. 사실·AP 해석·실무 행동을 분리한다. 공식 원문·발표일·확인 시각 필수. 지난 발표를 오늘 발표처럼 표시하지 않는다. 사실 확인이 안 되면 발행을 보류한다.
- PDF는 A4 세로, 표지+본문으로 읽기 편하게 작성한다. 원문 링크 클릭 가능. 이메일은 동일 기사 요약과 웹·PDF 링크를 제공한다.
- AI 작성 및 출처 검증임을 밝히며 사람의 검수를 받았다고 임의 표시하지 않는다.

## 구독·운영
- 한국어 무료 일일 구독, 매일 오전 8시 KST를 목표로 발행. 계정 없는 이메일 확인 방식. 구독 문의는 기존 회사 메일로 연결.
- 수집 동의는 기본 미선택. 이메일 확인 전에는 뉴스레터를 보내지 않는다. 이메일 확인은 48시간 유효한 일회성 토큰. 해지는 서명 토큰으로 확인하고 즉시 발송 대상에서 제외한다.
- 개인정보는 Supabase의 서비스 전용 테이블에 저장한다. 외부 방문자는 구독자 목록을 읽을 수 없다. 관리자 권한은 기존 AP 관리자 계정 UUID로 판정한다.
- Resend API로 회사 도메인 메일 발송. 키/도메인이 미설정이면 신청은 pending에 보관하고 준비 상태를 정확히 보여준다. 실제 발송 확인 없이는 자동 발송 완료라고 보고하지 않는다.
- 관리자 화면에 활성/확인대기/해지 숫자, 발행호, 발송상태, 실패사유 표시. 발송은 활성 구독자에 한해 개별 처리하고 호별·구독자별 중복 방지.
- 매일 이 채팅 자동화가 공식 뉴스 검색·검증, 일일판 원본 작성, 웹/PDF 생성 및 확인, 기존 저장소 배포, DB 발행호 등록을 수행한다. 메일은 서버가 확정된 발행호만 발송한다. 불확실하거나 접근/설정 오류 시 초안을 보존하고 필요한 조치만 알린다.

## 검증
동의 누락·잘못된 주소 거절, 이메일 확인 전 발송 금지, 만료 토큰 거절, 해지 이후 발송 금지, 호별 중복 방지, 방문자 개인정보 접근 차단, 데스크톱/모바일 레이아웃, PDF 한글·링크·페이지 넘침, 기존 뉴스 링크 유지 확인.
