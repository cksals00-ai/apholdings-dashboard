# AP Holdings 홈페이지 문구 개편
2026-10-09 사용자가 채팅에서 승인한 문구 방향을 구현한다.
- 한국어 메인, 회사 소개, 5개 사업 허브와 제품 설명을 쉬운 합니다체로 작성한다.
- 첫 화면에서 식품 정보, 교육, 게임, AI 콘텐츠, 해외 판매 사업을 명시한다.
- 기존 디자인, 링크, 기능, 다른 언어와 뉴스 기사 원문은 보존한다.
- 준비 중인 판매·가맹·게임 기능은 운영 사실처럼 표현하지 않는다.
- 개인정보 설명은 서비스별 범위를 명시한다. 최초·전체·항상 등 입증되지 않은 표현은 제거한다.
- 현재 생성 방식에 맞추어 canonical 원고와 idempotent 후처리를 함께 저장한다.
- 정적 링크 검증, 문구 검토, 데스크톱 및 모바일 화면 확인 후 기존 Pages에 게시한다.
