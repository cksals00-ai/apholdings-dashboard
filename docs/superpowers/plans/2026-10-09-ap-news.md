# AP News Daily Implementation Plan

> For agentic workers: Execute inline using executing-plans; no agent delegation is needed.

**Goal:** 기존 AP뉴스에 브랜드 일일판, PDF, 이메일 확인 구독과 반복 운영을 추가한다.

**Architecture:** JSON 일일판을 하나의 원본으로 웹·이메일·PDF를 생성한다. Supabase Edge Function이 구독과 메일 큐를 처리하고 pg_cron이 큐를 실행한다. 이 채팅 자동화가 매일 공식 뉴스를 검증하여 기존 GitHub Pages 저장소에 추가한다.

**Tech Stack:** 기존 Python 정적 빌더, 표준 JS/HTML/CSS, ReportLab, Supabase PostgreSQL 및 Deno Edge Functions, Resend HTTP API.
