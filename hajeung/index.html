01

로그인

회사 이메일과 개인 앱 코드로 시작합니다.

이 화면 여는 방법
앱을 처음 실행하면 표시됩니다.

화면에 있는 기능

  1. 회사 이메일

    관리자에게 신청한 본인 회사 이메일을 입력합니다. Apple ID가 아닙니다.

  2. 앱 코드

    관리자가 개별 전달한 코드를 입력합니다. 다른 담당자 코드를 함께 쓰지 마세요.

  3. 로그인

    두 항목을 입력한 뒤 누릅니다. 성공하면 홈으로 이동합니다.

이렇게 사용하고 확인하세요

신청 → 관리자 승인 → 개인 코드 전달 순서가 먼저 필요합니다. 코드가 없으면 아래 계정 신청을 이용하세요.

잠깐 확인해 주세요
로그인되지 않으면 이메일 오타와 코드 전달 여부를 확인하고 오류 문구만 접수해 주세요. 코드는 사진에 담지 마세요.

02

홈 · 오늘 확인할 증권

종료일이 가까운 자료를 먼저 살펴보는 시작 화면입니다.

이 화면 여는 방법
로그인 후 또는 하단 홈을 누릅니다.

화면에 있는 기능

  1. 지금 급한 증권

    확인이 필요한 건수를 한눈에 봅니다. 화면의 1건은 안내용 가상 값입니다.

  2. 종료일 경과·30일 이내·60일 이내·정상

    기간 구간별 현황을 구분해서 확인합니다. 숫자만으로 업무가 완료됐다고 판단하지 마세요.

  3. 증권 카드·증권 촬영해서 등록

    업체 카드를 누르면 상세, 하단 검은 버튼을 누르면 등록 화면으로 이동합니다. 촬영이 바로 시작되는 것은 아닙니다.

이렇게 사용하고 확인하세요

카드에서 업체·공사·현장·종료일을 읽고 해당 건을 엽니다.

잠깐 확인해 주세요
자료가 보이지 않으면 목록의 전체 보기와 새로고침을 확인하세요.

    업체명·현장·남은 일수·종료일을 확인한 뒤 카드를 눌러 상세를 엽니다.

잠깐 확인해 주세요
저장한 건이 없으면 검색어·필터를 초기화하세요. 같은 자료를 다시 등록하기 전에 확인해 주세요.

    서로 다른 증권을 구분하는 정보입니다. 시험 자료는 TEST 등 명확한 가상 표시를 넣습니다.

예: 업체명 테스트업체_본인이름, 공사명 사용법 확인용, 현장 가상현장, 증권번호 TEST-본인이름. 아래로 내려 금액·날짜를 입력하세요.

잠깐 확인해 주세요
AI 동의가 나오면 내용을 읽고 선택하세요. 원하지 않으면 AI 없이 첨부, 업로드 자체를 원하지 않으면 취소합니다. AI가 채운 번호·금액·날짜는 반드시 원본과 대조합니다.

화면에 있는 기능

  1. 보증금액·종료일 *

  2. 발급일 / 보증개시일

오른쪽 위 저장을 한 번 누릅니다. 목록에서 업체명이나 증권번호로 다시 찾아 입력값을 확인하세요. 취소는 저장하지 않고 돌아갑니다.

잠깐 확인해 주세요
저장 버튼이 비활성화되면 업체명 등 필수 입력을 확인하세요. 중복 증권번호 안내가 나오면 기존 자료를 먼저 확인하고 불필요한 중복 저장을 취소합니다.

3. 증권 조회·등록·수정하기
  1. 조회: iPhone 하단의 목록을 누릅니다. 검색창에 업체·공사·현장·증권번호를 입력하고, 전체 / 60일 이내 / 경과 / 종료·연장으로 결과를 좁혀봅니다. 홈의 ‘종료일 경과·30일 이내·60일 이내·정상’ 수치는 서로 구분해서 확인합니다.
  2. 상세: 업체명·증권번호·보증금액·종료일·상태와 표시되는 활동 기록을 확인합니다. 필터 때문에 보이지 않으면 전체 보기로 돌아가세요.
  3. 등록: 목록 하단의 증권 등록 또는 홈 하단의 증권 촬영해서 등록을 누르고 가상 업체명과 종료일 등 필수 항목을 입력합니다. 공사명·현장·증권번호·금액·비고도 가상 내용으로 작성하고 저장합니다.

  5. 수정: 등록한 가상 증권을 열고 아래로 내려 내용 수정을 누릅니다. 비고 등 한 항목을 바꾼 뒤 오른쪽 위 저장을 누릅니다. 다시 상세를 열어 변경 내용이 유지되는지 확인합니다.

버전·기기·권한에 따라 버튼 위치나 표시가 다를 수 있습니다. 등록·수정 버튼이 없으면 다른 사람 계정을 빌리지 말고 권한 확인을 요청하세요. 테스트 계정은 가상 자료의 등록·수정용이며 운영 데이터 이용 권한과 구분합니다.

첫 테스트 예시: ‘테스트업체_본인이름’ 등록 → 검색 → 비고 수정 → 재조회 → 결과를 이 페이지에 접수. 실제 사업자등록번호·연락처·증권 원본 대신 가상 값을 사용하세요.

3-1. 첫 증권 한 건을 함께 등록해 볼까요?
  1. 앱 하단 목록 → 증권 등록을 누릅니다. 촬영 없이 직접 입력부터 시작해도 됩니다.
  2. 업체명 *에 ‘테스트업체_본인이름’을 입력합니다. 다른 담당자가 만든 시험 자료와 구분하기 위한 이름입니다.
  3. 공사명은 ‘사용법 확인용’, 현장은 ‘가상현장’, 증권번호는 ‘TEST-20261028-본인이름’처럼 실제 증권과 구분되는 값으로 입력합니다.
  4. 보증금액에 ‘1,000,000원’, 종료일 *에는 테스트할 날짜를 선택합니다. 발급일·보증개시일은 해당 항목을 켜면 날짜를 선택할 수 있습니다. 입력 예시는 모두 가상 자료입니다.
  5. 비고에 ‘첫 등록 테스트’를 입력하고 오른쪽 위 저장을 누릅니다. 업체명은 비워둘 수 없습니다. 오류 문구가 나타나면 해당 항목을 먼저 확인하세요.
  6. 목록 검색창에 ‘테스트업체_본인이름’을 입력합니다. 한 건을 열어 업체명·증권번호·금액·종료일이 입력한 내용과 같은지 확인합니다.
  7. 상세 아래쪽의 내용 수정을 누르고 비고를 ‘수정 테스트 완료’로 바꿔 저장합니다. 다시 열어 바뀐 문구가 유지되면 등록·수정 확인이 끝납니다.

같은 증권번호가 있다는 안내가 나오나요? 기존 가상 자료가 있는지 먼저 확인하세요. 실수로 중복 등록한 것이라면 취소하고 목록에서 찾아 수정합니다. 중복 저장 확인을 무조건 누르지 않습니다.

저장 버튼을 눌러도 진행되지 않나요? 업체명이 입력됐는지, 문서 분석이나 저장이 진행 중인지, 네트워크 오류가 표시되는지 확인하세요. 같은 자료를 여러 번 만들기보다 오류 문구를 기록하고 문의해 주세요.

3-2. 홈·목록·발송함·설정은 언제 쓰나요?
  • 홈: 종료일이 지났거나 곧 끝나는 증권, 회신 대기와 이메일 누락 등 먼저 확인할 일을 살펴봅니다. ‘정상’ 숫자가 모든 업무 완료를 의미하는 것은 아닙니다.
  • 목록: 증권을 검색하고 상세를 열거나 새 증권을 등록합니다. 결과가 없으면 검색어를 지우고 ‘전체’를 선택해 보세요. 화면을 아래로 당기면 새로고침합니다.
  • 발송함: 승인 대기와 발송 이력을 확인하는 메뉴입니다. 테스트 계정에서는 실제 메일 발송이 차단됩니다. 버튼을 눌러 외부 업체에 보내는 것을 테스트 목표로 삼지 않습니다.
  • 설정: 본인 정보와 표시되는 설정을 확인합니다. 일반 담당자에게 관리자용 사용자·코드 발급 메뉴가 보이지 않는 것은 권한에 따른 정상 동작일 수 있습니다.

개인 앱 코드가 없으면 앱에 로그인할 수 없습니다. 지원 페이지의 이메일 확인 링크를 앱 코드 입력란에 붙여 넣지 마세요.

3-3. 점검·회신 기록, 상태 변경, 연장 증권은 어떻게 확인하나요?
  1. 목록에서 확인할 가상 증권을 엽니다.
  2. 점검·회신 기록 추가에서 화면에 표시되는 기록 종류를 고르고 내용을 적습니다. 관련 날짜를 확인한 뒤 저장하고 상세의 이력에서 반영 여부를 확인합니다.
  3. 상태 바꾸기는 증권의 업무 상태를 변경합니다. 화면에 표시되는 상태 설명을 읽고, 테스트 중인 가상 자료에만 적용하세요. 이전 상태와 변경할 상태를 요청에 적으면 확인에 도움이 됩니다.
  4. 실제 연장 문서를 받았을 때 사용하는 연장 증권 등록은 기존 증권과 새 증권을 연결합니다. 테스트에서는 가상 문서로만 진행합니다. 저장하면 이전 증권이 ‘연장완료’로 바뀌므로 단순 비고 수정과 구분하세요.
  5. 상세의 연장 이력에 이전·연장 증권 연결이 표시되는지 확인합니다. 일반적인 내용 변경은 ‘연장 증권 등록’이 아니라 ‘내용 수정’을 사용합니다.

버튼이 표시되지 않으면 설치 버전·담당자 권한을 먼저 확인해 주세요. 화면을 찾기 어렵다면 현재 화면을 사진으로 남겨주셔도 됩니다.

4. 사진·PDF 첨부와 AI 분석 확인
  1. 앱의 증권 등록·수정 화면에서 표시되는 촬영·사진·PDF 메뉴로 가상 문서를 선택합니다. 실제 고객·업무 문서를 테스트에 사용하지 않습니다.
  2. AI 분석 동의 화면이 표시되면 전송 대상과 항목을 읽고 문서마다 선택합니다. AI를 원하지 않으면 AI 없이 첨부를 선택하고, 업로드 자체를 원하지 않으면 취소합니다.
  3. AI가 입력한 값은 원본과 대조합니다. 특히 증권번호·보증금액·날짜를 직접 확인한 후 저장하세요. AI 결과를 확정값으로 간주하지 않습니다.
  4. 상세 화면에서 원본 보기와 저장 결과를 확인합니다. 파일 선택·촬영·미리보기가 실패하면 기기·파일 종류·앱 버전과 오류 문구를 접수합니다.

설치된 빌드에 해당 메뉴가 있을 때 이용하세요. 모든 기기의 촬영·PDF·AI 동작 검증이 끝났다는 의미는 아닙니다. 앱 문서 첨부와 아래 지원 게시판의 사진 첨부는 서로 별개입니다.

5. 휴대폰에서 수정 요청과 사진 보내기
  1. 회사 이메일 확인 링크로 이 페이지에 로그인한 뒤 수정 요청 탭을 엽니다.
  2. 오류 / 개선 제안 / 설치·도입·이용 문의 중 하나를 고릅니다.
  3. 제목과 내용에 진행 순서 → 기대한 결과 → 실제 결과를 적습니다. 발생 화면·앱 버전·기기/OS도 함께 입력하세요.
  4. 필요하면 스크린샷이나 촬영한 사진 한 장(5MB 이하)을 선택합니다. 비밀정보와 실제 업무 자료를 가린 후 올려주세요. 사진 없이도 접수할 수 있습니다.
  5. 요청 접수하기를 누르고 성공 안내를 확인합니다. 사진만 실패하면 안내되는 사진 재첨부 기능을 이용하세요.
  6. 내 요청에서 요청을 열어 답변·처리 상태를 확인합니다. 새로고침으로 최신 내용을 불러올 수 있습니다.

요청 내용·사진·답변은 작성자와 관리자만 볼 수 있습니다. ‘완료’는 해당 요청의 처리 상태이며 앱 정식 출시나 모든 오류 해결을 뜻하지 않습니다. 답변은 이 페이지에서 확인하며 자동 답변 메일을 약속하지 않습니다.

신청은 했는데 앱에 로그인할 수 없어요
웹 신청, 관리자 승인, 앱 코드 발급·개별 전달은 각각 다른 단계입니다. 신청 상태와 코드 수신 여부를 먼저 확인하세요.
등록·수정 버튼이 없어요
담당자 권한과 설치 빌드를 확인해야 합니다. 다른 사람의 코드를 사용하지 말고 신청 이메일과 화면 사진으로 문의해 주세요.
저장한 자료가 목록에 없어요
검색어와 필터를 초기화하고 ‘전체’에서 새로고침하세요. 저장 오류가 있었는지 확인하고, 중복 등록하기 전에 문의해 주세요.
앱에서 사진·PDF를 열 수 없어요
기기·OS·앱 버전과 파일 종류를 알려주세요. 원본에 실제 업무 정보가 있으면 전송하지 말고, 가상 파일로 재현하거나 오류 화면만 첨부해 주세요.
수정 요청에 사진을 올리지 못했어요
사진은 한 장, 5MB 이하이며 JPEG·PNG·WebP를 지원합니다. HEIC 사진은 JPEG로 내보내거나 스크린샷으로 준비하세요. PDF는 지원 게시판의 사진 첨부 대상이 아닙니다. 요청 저장 후 사진만 실패하면 ‘저장된 요청에 사진 다시 첨부’를 이용하세요.

하자증권 앱은 iPhone·Android 모두 무료 다운로드 기준입니다. 스토어에서 앱을 내려받는 것과 업무 자료에 접근하는 권한은 다릅니다. 관리자가 승인한 회사 이메일과 개인 앱 코드로 로그인해야 이용할 수 있으며, 공개 회원가입은 제공하지 않습니다. 현재 iPhone은 TestFlight, Android는 정식 출시 심사 제출 요청 단계이므로 실제 설치 가능 여부는 위 안내를 확인해 주세요.
