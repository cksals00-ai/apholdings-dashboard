GitHub · 발표 2026-11-06

GitHub가 Copilot 코드 리뷰의 관리와 확인 기능을 넓혔습니다.

AI 제작 · 편집 일러스트 · 실제 제품 화면 아님

GitHub는 11월 6일 Copilot 코드 리뷰 설정을 관리하는 REST·GraphQL API와 검토 개요 개선을 발표했다. 검토·댓글의 Copilot 귀속 정보, 제공되는 경우의 검토 노력 메타데이터, 사용한 지침 등의 출처를 확인할 수 있다. 건너뛴 파일과 제외된 파일도 개요에서 함께 보여준다. API 권한과 지원 인증 방식은 관리 범위에 따라 다르다.

AP의 관점
AP가 웹 서비스 변경을 검토한다면, AI의 승인 표시만 보지 않고 제외된 파일과 적용 지침까지 확인하는 절차를 둘 수 있다.

AI 사용량, 도입 성과와 구분해서 읽기

GitHub · 발표 2026-11-06

Copilot 영향 대시보드에 채팅과 VS Code 에이전트 사용이 추가됐습니다.

AI 제작 · 편집 일러스트 · 실제 제품 화면 아님

GitHub는 영향 대시보드의 28일 보고서에 Copilot Chat과 VS Code 에이전트 사용을 추가했다. 기능 참여는 해당 기간 중 최소 이틀 사용한 경우를 뜻하며 여러 기능의 사용자가 겹칠 수 있다. 이 두 기능의 참여는 도입 단계 계산에는 포함되지 않는다. 기존 Passive users 명칭은 Chat-first users로 바뀌지만 집단 크기는 그대로다.

AP의 관점
AP의 AI 교육 효과를 살핀다면, 사용 빈도와 별개로 과제 완성도와 재작업 시간을 확인하는 평가를 설계할 수 있다.

대화에서 변경 요청까지, 협업 채널의 확장

GitHub · 발표 2026-11-06

Slack·Teams의 GitHub Copilot 연동이 일반 제공됐습니다.

AI 제작 · 편집 일러스트 · 실제 제품 화면 아님

GitHub는 Slack과 Microsoft Teams의 Copilot 연동 일반 제공을 발표했다. 대화에서 @GitHub를 불러 버그 조사, 이슈 생성, 변경 구현과 풀 리퀘스트 열기를 요청할 수 있다. Teams에서는 Canvas로 계획과 코드 등을 대화 옆에서 검토한다. 생성된 이슈와 풀 리퀘스트 설명에는 요청한 대화와 사용자의 귀속 표시가 포함된다.

AP의 관점
AP가 고객 지원 대화를 개발 업무로 연결한다면, 요청 맥락을 남긴 변경 제안과 담당자의 검토 단계를 함께 설계할 수 있다.

AWS · 발표 2026-11-06

AWS는 에이전트 설계를 위한 구성 요소의 분류 틀을 소개했습니다.

AI 제작 · 편집 일러스트 · 실제 제품 화면 아님

AWS는 Amazon Quick의 에이전트 구성 요소를 설명하는 설계 글을 공개했다. 언제·무엇이 실행을 시작하는지, 누가 수행하는지, 어떤 도구·스킬·워크플로를 사용하는지를 구분한다. 시작 조건에는 사람의 요청, 위임, 예약, 이벤트가 포함된다. 이는 설계 개념을 정리한 글이며 새로운 기능의 일반 제공 발표와는 구별된다.

AP가 뉴스레터 업무를 점검한다면, 예약 실행과 제작 완료, 실제 공개와 메일 접수를 각각 확인하는 기준을 둘 수 있다.

AWS · 발표 2026-11-06

Taxbit 사례는 역할과 조직에 따른 AI 답변 범위를 보여줍니다.

AI 제작 · 편집 일러스트 · 실제 제품 화면 아님

AWS는 Amazon Bedrock AgentCore를 활용한 Taxbit Assist 구축 사례를 소개했다. 제품 대시보드에 통합된 도우미는 근거를 제시하고 사용자 역할과 조직 맥락을 반영하도록 설계됐다. 지역별 데이터 보관과 지속적인 품질 측정도 다룬다. 세무 자문을 제공하는 기능으로 설명하지 않으며, 다른 기업의 동일한 성과를 보장하는 발표도 아니다.

AP의 관점
AP가 기업 고객 지원에 AI를 검토한다면, 고객별 열람 가능한 문서와 답변 근거를 연결하고 근거가 부족할 때의 안내를 설계할 수 있다.
