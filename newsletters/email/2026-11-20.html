Genie 4 API, 움직이며 바꾸는 가상 세계

Google Blog · 발표 2026-11-19

Google은 Genie 4를 Gemini API와 AI Studio에서 개발자가 실험할 수 있도록 공개했습니다.

AI 제작 · 편집 일러스트 · 실제 제품 화면 아님

Google은 11월 19일 Genie 4의 Gemini API 제공을 발표했습니다. Interactions API와 Google AI Studio에서 텍스트·참조 이미지 또는 둘을 함께 입력해 연속적인 가상 세계를 실험할 수 있습니다. 발표에 따르면 해상도는 720p, 초당 24프레임이며 환경음·효과음·대화 등 오디오를 함께 생성합니다. 키보드와 실시간 텍스트 지시로 이동하거나 날씨·조명·사물·사건을 바꿀 수 있고, 출력에는 SynthID 워터마크가 포함됩니다. 사용 전 가격과 API 문서를 확인하도록 안내하며, 한국의 모든 계정에서 무료라는 발표는 아닙니다.

AP의 관점
AP의 AI 교육이나 콘텐츠 기획에 참고한다면, 가상 공간의 변화와 소리·장면의 일관성을 비교하는 수업안을 제안합니다. 실제 공간의 물리적 정확성이나 로봇 학습 효과를 입증한 결과와 생성 시연을 구분해 설명할 수 있습니다.

Copilot 연결 서비스 8개 추가, 권한도 함께 확인

GitHub Blog · 발표 2026-11-18

Supabase·Box·Calendly 등 8개 서비스의 GitHub 검증 커넥터가 공개 미리보기로 추가됐습니다.

AI 제작 · 편집 일러스트 · 실제 제품 화면 아님

GitHub는 11월 18일 Copilot에 연결할 수 있는 서비스 8개를 추가했습니다. Box, Buildkite, Calendly, ClickUp, Mixpanel, Supabase, Webflow, Wix가 대상입니다. GitHub가 검증한 MCP 서버를 통해 자료·프로젝트·데이터베이스 등의 도구를 연결하는 방식입니다. 모든 Copilot 요금제에서 공개 미리보기로 제공하지만 Business·Enterprise는 관리자가 Editor preview features 정책을 켜야 합니다. 커넥터별 허용 목록을 쓰는 기업은 새 항목도 추가해야 하고, 연결할 서비스 쪽의 별도 관리자 허용이 필요한 경우도 있습니다.

AP의 관점
AP의 웹 서비스나 Lia Select 자료 흐름에 참고한다면, 가상 자료를 읽는 기능과 실제 수정 권한을 나누는 설계를 제안합니다. 연결 성공 여부와 필요한 작업의 최소 권한을 각각 확인하면 도구 추가의 영향을 구체적으로 살펴볼 수 있습니다.

팀 공통 플러그인, 개인 선택과 조직 정책 사이

GitHub Blog · 발표 2026-11-18

Copilot Business·Enterprise에서 조직 팀의 공통 플러그인 설정이 일반 제공됩니다.

AI 제작 · 편집 일러스트 · 실제 제품 화면 아님

GitHub는 11월 18일 조직 팀을 위한 Copilot 맞춤 설정을 일반 제공한다고 발표했습니다. 팀 관리자와 조직 소유자는 승인된 Agent Plugins를 팀 기본값으로 선택할 수 있습니다. 선택한 플러그인은 VS Code·Copilot 앱·CLI에서 팀의 직접 구성원에게 기본 활성화되며 하위 팀 구성원에게 자동 상속되지 않습니다. 정책이 허용하면 구성원은 자신의 클라이언트에서 팀 플러그인을 끌 수 있습니다. 기업·조직의 허용·필수·차단 정책이 팀 선택보다 우선하며, 대상은 Copilot Business와 Enterprise입니다.

AP의 관점
AP의 기업 AI 교육에 참고한다면, 공통 수업 도구와 개인 선택·조직 필수 설정을 나눈 안내표를 제안합니다. 같은 팀이라는 이유만으로 하위 팀까지 같은 도구가 적용된다고 가정하지 않고 실제 적용 대상을 확인할 수 있습니다.

Copilot 코드 검토, 변경 위험에 맞춰 깊이 조정

GitHub Blog · 발표 2026-11-17

Adaptive 검토와 공개 저장소 간 맥락·비밀정보 탐지가 공개 미리보기로 소개됐습니다.

AI 제작 · 편집 일러스트 · 실제 제품 화면 아님

GitHub는 11월 17일 Copilot 코드 검토의 새 기능을 발표했습니다. Adaptive는 변경의 복잡성과 위험에 따라 Lite·Balanced·Max 중 검토 수준을 선택하고 선택한 수준을 표시합니다. 조직·저장소 등의 최대 수준을 넘지 않으며 기존 기본값은 Balanced입니다. 관련 공개 저장소를 참고하는 기능과 노출된 비밀정보를 검토 의견으로 지적하는 기능도 공개 미리보기입니다. 이 기능들은 Pro·Pro+·Max·Business·Enterprise 요금제가 대상입니다. 비밀정보 탐지는 설정에서 활성화해야 하며 모든 유출을 막는다는 보장은 아닙니다.

AP의 관점
AP의 웹 구현에 참고한다면, 문구 수정과 인증 로직 변경에 필요한 검토 항목을 달리 정하는 방식을 제안합니다. 자동 의견이 없는 경우도 실제 시험과 비밀정보 검사를 별도로 확인하고, 선택된 검토 깊이와 수정 결과를 함께 남길 수 있습니다.

Copilot Evals, 한 번의 좋은 답보다 반복 비교

GitHub Blog · 발표 2026-11-17

스킬·에이전트·MCP 도구의 동작을 같은 과제로 비교하는 Copilot Evals가 공개 미리보기로 나왔습니다.

AI 제작 · 편집 일러스트 · 실제 제품 화면 아님

GitHub는 11월 17일 Copilot Evals의 공개 미리보기를 발표했습니다. 현실적인 과제와 좋은 결과의 기준을 정하고 결과뿐 아니라 수행 과정도 확인하는 평가 도구입니다. 스킬·에이전트·MCP 도구의 평가를 만들고, 통과·실패 원인을 살피며 변경 전후 실행을 비교할 수 있습니다. 각 실행은 시작 전 사용자가 승인합니다. 로컬 평가 도구 Vally를 엔진으로 사용하며 VS Code 확장과 CLI·Copilot 앱 플러그인으로 설치합니다. Individual·Business·Enterprise가 대상이며 한 번의 통과가 모든 작업의 정확성을 뜻하지 않습니다.

AP의 관점
AP의 교육·콘텐츠 제작 절차에 참고한다면, 공개 자료의 요약에서 날짜·근거·빠진 조건을 확인하는 작은 평가표를 제안합니다. 지시문을 바꿀 때 같은 과제를 다시 비교하고, 잘된 답 하나보다 반복 결과와 실패 원인을 보고 개선을 판단할 수 있습니다.
