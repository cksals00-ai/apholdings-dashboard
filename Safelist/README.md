# 세이프리스트 (Safelist) v1.0

에이피홀딩스 7호 앱. 아토피·식품알레르기 아이 보호자를 위한 성분 대조 도구.

## 여는 법
`Safelist.xcodeproj` 를 더블클릭하면 끝입니다.

이 프로젝트는 **objectVersion 77**(1호 Iron & Grace와 같은 방식)이라
`Safelist/` 폴더 안의 파일이 **자동으로 포함**됩니다.
3호처럼 Add Files 를 따로 할 필요가 없습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `SafelistApp.swift` | 진입점 · 탭 4개 |
| `Allergens.swift` | **성분 데이터.** 법정 22종 + 자주 걸러내는 것 + 첨가물 (41항목) |
| `Matcher.swift` | **판정 엔진.** 표시란 추출 → 대조 |
| `AvoidStore.swift` | 회피 목록 · 기록 저장 (기기 안 JSON) |
| `Models.swift` | 기록 모델 |
| `CheckView.swift` | 붙여넣기 → 판정 (**심장**) |
| `AvoidListView.swift` | 회피 목록 설정 |
| `HistoryView.swift` | 기록 · 피드백 |
| `GuideView.swift` | 안내 · MD크림 실비 가이드 |
| `OnboardingView.swift` | 첫 실행 4장 |
| `Theme.swift` | 색 |

## 판정 규칙 (핵심)

1. 붙여넣은 문구에서 「알레르기…」 를 앵커로 **표시란**을 잘라낸다
2. **표시란이 있으면** → 법정 22종은 표시란 안에서만 본다
   (본문까지 뒤지면 「아몬드밀크」의 "밀크칼슘"이 우유로 걸려 전부 빨간불이 된다)
3. 표시 의무가 없는 항목(참깨·팜유·색소 등)은 원재료 본문에서 찾는다
4. **초록불은 없다.** 🔴 걸림 / ⚪ 확인 안 됨 두 가지뿐

## 검증한 사례 (2026-08-26)

| 입력 | 결과 |
|---|---|
| 초코파이 (표시란 있음) | 🔴 계란·우유·대두·밀(표시란) + 팜유(본문) |
| 쌀과자 "사용하지 않았습니다" | ⚪ 회피 항목 없음 |
| 하리보 (돼지껍질유래 젤라틴) | 🔴 돼지고기(표시란) + 젤라틴(본문) |
| 아몬드밀크 "밀크칼슘" | ⚪ **오탐 없음** ← 규칙 2로 해결 |
| 표시란 없는 원재료만 | 🔴 팜유·타르색소(본문) |
| 알레르기와 무관한 문장 | ⚪ 판단 불가 |
