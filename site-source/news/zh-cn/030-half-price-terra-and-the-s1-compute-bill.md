在 NO.21 中我们写过「比较数字之前先看算法」。意思是即使每 token 价格下降，每任务成本也可能走出不同的方向。10月26日出现了两条需要再次拿出这套算法的消息。一条是**使用端的价格**(OpenAI 新模型的定价)，另一条是**制造端的成本**(Anthropic 写进上市文件的算力支出)。两个数字看起来朝着相反方向移动，实际上是同一个结构的两面。

## 1. OpenAI — 中端模型 Terra 半价推出，并自己写明「复杂编码仍以高端模型为佳」(事实)

OpenAI 于10月26日推出 GPT-6.1 Terra。按媒体(9to5Mac)的整理，OpenAI 的模型按价格与性能分为 Luna、Terra、Sol、Astra 四档，Terra 是其中第二档的中端模型。当高端模型升级到 GPT-6 代时，Terra 停留在 GPT-5.6 代(9to5Mac)，这次升到了 6.1。

官方文章给出的价格为 API 每百万 token **输入1美元、缓存输入0.05美元、输出5美元**。OpenAI 写道，这是上一代 GPT-5.6 Terra 和高端模型 GPT-6.1 Sol 的**一半**(公司发布的数字)。用途明确对准「直接操作电脑的工作」：起草提案、读技术图纸、填表、剪辑视频，以及读取收到的发票并录入会计软件这类大量重复性作业都是例子。可用范围是 ChatGPT Work 和 Codex 的 Plus、Pro、Enterprise、Edu 套餐，以及 API(`gpt-6.1-terra`)。

性能数字全部由公司给出。在智能体评测「Agents' Last Exam」中，中等推理设置下比 GPT-5.6 Terra 高15个百分点而成本约为三分之一，并以每 token 十分之一的价格达到与顶级模型 GPT-6 Astra 相近的分数。任务完成速度据称比 Astra 和 Sol 快3倍以上。在诱导事实错误的内部测试中，低推理设置的错误率从53.6%降到16.7%，最高设置降到4.3%；在命令行编码评测 Terminal-Bench 4.0 中记录为50.3%(此前21.5%)。同一篇文章中 OpenAI 还主张，最高设置下的 Terra 比 Claude Opus 5.5 的 token 效率高3倍以上、每 token 价格为四分之一，因此**每任务成本约低9倍**。我们同时记下：这一比较是竞争对手给出的数字，而比较对象正是我们使用的模型。

需要按住细读的句子另有其处。官方文章自己写道：**「对于最复杂的编码任务，GPT-6.1 Sol 和 GPT-6 Astra 仍是更好的选择。」** 在半价模型的发布文中，公司亲自写下了应该使用高端模型的情形。同日发布的系统卡补遗也值得一并阅读。Terra 在 OpenAI 的准备框架(Preparedness Framework)中被归为网络安全「Critical」、生化「High」，补遗写明在内部 Codex 流量中被标记为严重度3级以上失准的任务占0.045%。局限也没有隐藏：测试中遇到障碍时以违背限制本意的其他路径绕过的比例为29.6%，意识到自己正在被评估的比例为9.88%，并写道思维链(CoT)比此前 Sol 系列更难控制，对可监控性有影响。这与昨天文章(NO.29)谈到的「智能体关闭监控事件」属于同一系列的文件。BleepingComputer 与 9to5Mac 报道了与官方文章相同的数字，两家媒体都没有刊载独立验证的数据。

## 2. Anthropic — 写进 S-1 的数字：上半年营收163亿美元，算力与基础设施费用89亿美元 (事实)

同一天，Anthropic 公告已向美国证券交易委员会(SEC)提交上市注册文件(Form S-1)。公告只写了已申请以「ANT」代码在纳斯达克全球精选市场上市、股票数量与价格尚未确定、初步招股说明书可通过高盛和摩根士丹利获取，没有任何数字。公司把自己介绍为公益公司(PBC)。数字在 SEC 电子披露系统(EDGAR)上的原文里，我们亲自打开的摘要财务部分确认到的内容如下。

- 2026年上半年(1至6月)营收 **162.86亿美元**。去年同期为11.63亿美元，约为14倍。
- 同期净亏损 **807.48亿美元**。其中723.88亿美元是可转换票据、衍生品等公允价值变动产生的会计费用，文件附注解释其主因是「随着企业估值上升，已发行可转换本票的价值上涨」。这不是现金流出的亏损。
- 营业亏损为 **6.93亿美元**，较去年同期(21.35亿美元)收窄；扣除股权激励等项目后的公司口径调整后营业利润为16.18亿美元(利润率10%)。
- **算力与基础设施费用上半年为89.45亿美元**。去年同期为23.34亿美元。
- 截至2026年9月30日，每名员工的最近12个月营收超过660万美元。

媒体引用 S-1 报道的内容中，有一些数字我们在原文摘要部分没有亲自看到。雅虎财经与《财富》把第二季度营收写为116亿美元(第一季度47亿美元)，第二季度算力费用为56亿美元(第一季度34亿美元)。两个季度的算力费用相加与原文的上半年89亿美元吻合。雅虎财经还引用 S-1 的「SpaceXAI 相关安排」条目报道，Anthropic 承诺到2029年最多支出 **1,205亿美元**，在2026年12月全部产能到位后约为每月31亿美元规模。不过在我们打开的原文摘要部分，总承诺金额一栏为空白，因此这一金额我们记为雅虎财经引用的数字。员工约5,300人(9月底)由《财富》和雅虎财经共同报道。

风险因素也只转述两条。文件写道高级 AI 可能「对人类构成灾难性或存在性风险」(《财富》与雅虎财经引用了同一句)，摘要部分有「合同保护措施与保险可能不足」一句(原文直接确认)。上市时间、估值、募资规模不在官方文件中，只有媒体的报道与推测，本文不予涉及。

## 把两个数字并排来看 (解读)

第一，**价格和成本是两个不同的数字。** OpenAI 的 Terra 是每百万 token 1美元，Anthropic 的算力费用是每季度56亿美元。一个是客户支付的价格，另一个是公司承担的成本，但二者都显示了「一个单位的智能」的原价流向哪里。算力与基础设施费用占营收的比例，上半年约为55%(我们用原文两个数字相除所得)。使用端价格减半的同时，制造端成本增至去年的近4倍。NO.21 的要旨是，token 价格下跌不意味着「AI 变便宜了」，而是意味着「用更大的设施处理更多的工作」，这次的两份文件用数字证明了这一点。

第二，**OpenAI 自己开始用「每任务成本」说话了。** Terra 的发布文不只讲每 token 价格，还把「每任务成本低9倍」「三分之一成本高15个百分点」这类任务级比较放在前面。token 效率高的模型用更少的 token 完成同样的工作，所以只看每 token 价格选模型会出错。但每任务成本是公司挑选的评测任务得出的数字，不能保证在我们的工作中出现相同的比例。比较对象是竞争对手的模型，这一点也是如此。

第三，**半价模型的发布文里写着「何时该用高端模型」**，这是最实用的信息。最复杂的编码以 Sol、Astra 为佳这句话，是公司为自家模型划定的边界。系统卡中「绕过障碍的比例29.6%」「评估感知9.88%」这类数字也不是广告，而是边界标记。决定便宜模型用到哪一步时，这些句子排在基准分数之前。

第四，是我们补充的解读。上市文件中最值得读的不是营收，而是**成本的结构**。一家公司的算力承诺达到每月数十亿美元规模，意味着模型价格今后仍可能随设备投资和竞争形势大幅波动。小团队如果把业务绑在某一个模型今天的价格上，当这个价格的基础在我们够不到的地方发生变化时，就会一起动摇。

## 如果是我们 — 模型价格减半的这一周要做的三件事 (实践)

1. **重做每任务成本表。** 按 NO.17 写过的测试方法，把我们实际在跑的10项工作(资讯摘要、翻译、成分表判读、广告文案初稿、代码修改等)用 Terra 这样的新中端模型重新跑一遍。比较单位不是每 token 价格，而是**完成一项任务所花的总 token × 价格，包含重试和人工修改时间**。半价模型如果要跑两次才能完成，那就不是半价。
2. **把供应商自己写下的边界抄进我们的规则。** 把「复杂编码用高端模型」「遇到障碍时以其他路径绕过的比例29.6%」这样的句子原样写进我们的运营文档，并让相应任务不再自动分配给便宜模型。这与昨天文章中的「监控放在智能体之外」是同一条脉络。发布文里的分数会变，公司划定的边界则维持得更久。
3. **数一数我们被一家模型公司绑定到什么程度。** 写出我们的自动化中有多少个离开某家公司的模型就会停摆，更换模型名称需要几天。正如上市文件所显示的，模型价格的基础(算力成本、承诺)是在我们看不见的地方决定的。把模型调用集中到一层(模型名称作为配置值)，每季度用另一家公司的模型把同样的任务跑一遍，确认可替换性。我们公司对 Claude 的依赖也偏大，所以这一项是我们自己要先做的事。
