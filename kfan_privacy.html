Privacy Policy

K-Concert Trip · A.P Holdings · Last updated 29 October 2026

Short version: There is no account, advertising SDK or analytics SDK. Your trip entries stay on your phone. Downloading public place updates sends a network request to our hosting provider, which logs IP addresses for security.

Information we collect

K-Concert Trip has no sign-up, login or user profiles. We do not upload your name, email, trip entries, contacts or photos. Public data downloads disclose the connection IP address to GitHub Pages, our hosting provider. GitHub logs and stores visitor IP addresses for security; this is not used by us to infer location or target advertising.

Information stored on your device

The app saves the following locally, so it can show your countdown and remember your progress:

  • The trip name, date and venue you enter yourself
  • Which checklist items you have ticked off

This data never leaves your device. It is not backed up to our servers, because we do not operate any server that receives user data. Deleting the app deletes this data permanently.

Network use

Once per launch, the app downloads a single static file of nearby-place information (accommodation, restaurants and attractions around each venue) from our public website. The request includes the network IP address and the requested public file. GitHub processes these connection details under its own privacy statement. We do not receive individual IP logs from GitHub Pages. See GitHub Pages data collection and the GitHub Privacy Statement. If the download fails, the app continues to work fully from the data bundled inside it.

Retention and deletion

Local entries can be removed by deleting the trip or app. Hosting security logs are retained by GitHub under its policy; we cannot identify or delete an individual hosting log ourselves. Privacy requests about those logs can be made through the GitHub Privacy Statement linked above.

Where place information comes from

Nearby-place data is sourced from the Korea Tourism Organization public open data service. It is provided for information only and does not indicate live availability or pricing. Please confirm details with the venue or property directly.

Links to other websites

The app contains links that open your browser at third-party travel sites (for example, accommodation and transport booking services) and map applications. Some of these links may include an affiliate parameter, which means we may receive a commission if you make a booking. This costs you nothing extra and does not change the price you see. Once you leave the app, the privacy policy of that website applies — we receive no personal information about your booking.

Children

The app is a general-audience travel guide and does not ask children for account or trip information. The hosting security logs described above may be generated whenever an update is downloaded.

Third-party content

All venue guidance in the app is written by A.P Holdings. The app does not use artist names, photographs, logos, or fan-created material, does not host event schedules, and does not sell or resell tickets.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new date.
