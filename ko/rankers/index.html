같은 캐릭터. 같은 티어.
세 가지 도전.

퀴즈랭커 · 투자랭커 · 호텔랭커의 공통 성장 체계입니다. RP와 티어는 세 게임 공통의 성장 기준입니다. 각 앱의 포인트는 그 앱에서만 사용하고, 숙련도는 캐릭터와 함께한 경험을 보여줍니다.

현재와 다음 업데이트

퀴즈랭커 1.2는 심사 대기 중입니다. 아래 RP 구간과 퀴즈 능력은 현재 코드 기준입니다. 투자·호텔의 통합 계정과 RP 서버 연결은 TestFlight 온라인 검증 단계입니다. 앱별 포인트는 분리하며, 아래 캐릭터 능력 소개와 티어 장식 혜택은 통합 업데이트 기준안입니다.

RP · 랭킹 포인트

티어와 통합 순위의 기준. 공식 게임의 서버 정산으로만 변화합니다. 구매·선물·환전할 수 없습니다.

포인트 · 앱별 재화

캐릭터 해금·꾸미기·선택형 콘텐츠에 쓰는 재화. RP와 순위를 직접 올리지 않습니다. 포인트 잔액은 게임끼리 합치거나 이전하지 않습니다.

숙련도 · 캐릭터 경험

캐릭터별 플레이 경험과 칭호. RP 티어와 별도로 표시합니다. 투자·호텔의 새내기~명인은 숙련도 칭호로 정리합니다.

통합 티어 · 16단계

브론즈 III에서 레전드까지. 기존 RP는 보존하고, 신규 가입은 0 RP(브론즈 III)에서 시작합니다. 세 앱은 같은 계정의 RP를 읽습니다. 최고 티어를 ‘마스터’라고 부르지 않아 분야별 숙련도 칭호와 구분합니다.

브론즈·실버(1,200 RP 미만)는 패배 감점을 보호합니다. 골드 이상도 현재 세부 티어의 시작 RP 아래로 내려가지 않는 퀴즈 규칙을 공통 기준으로 사용합니다. 승급 보상은 해당 단계 최초 달성 때만 지급합니다.

한 판이 RP에 반영되는 방법

퀴즈 · 현재 규칙

순위 점수 + 정답률 보정 + 정답 수 보너스에 참가 인원 보정을 적용합니다. 2인 보정 0.5배, 6인 1배. 한 판 변화는 −30~+150 RP 안으로 제한하고 티어 바닥 보호를 적용합니다.

투자 · 통합 설계

동일 시나리오·시작 자금·기간의 공식 시즌에서 수수료 반영 수익률을 비교합니다. 파산·중도 포기·취소는 별도 처리하며 유리한 시나리오의 원점수를 직접 합산하지 않습니다.

호텔 · 통합 설계

동일 호텔·시즌·직무의 확정 경영 성과를 비교합니다. 수익·서비스·지속 가능성을 반영한 비교 점수로 백분위를 구합니다. 직무별 원점수를 섞지 않습니다.

투자·호텔 백분위 → RP 환산 기준안

아래쪽에서부터의 백분위 P를 0~100으로 정의합니다(상위 10%는 P=90). p=2P/100−1, 기본 변화는 p≥0이면 20+80p, p<0이면 20+50p입니다. P=100: +100 / P=90: +84 / P=50: +20 / P=10: −20 / P=0: −30 RP. 퀴즈의 순위 점수 곡선을 사용하며, 별도의 정답 보너스는 붙이지 않습니다.

공식 비교 표본이 20명 미만이면 RP 정산을 보류합니다. 동점은 평균 순위를 사용하고, 확정 결과만 한 번 반영합니다. 정산 시 동일한 티어 바닥 보호를 적용합니다. 환산 정산 함수는 서버에 반영되어 온라인 검증 중입니다. 정식 서비스 적용 시 마감된 비교 결과를 기준으로 반영합니다.

게스트·봇·오프라인 연습·체험 시나리오는 공식 RP와 공개 순위에 반영하지 않습니다. 공개 순위는 동의한 계정의 닉네임과 지표만 표시합니다. 통합 순위는 누적 RP, 게임별·분야별 순위는 해당 게임의 지표를 함께 표시합니다. RP 동점은 같은 순위입니다.

같은 티어 · 게임별 혜택

티어 혜택은 통합 업데이트에서 적용할 공통 보상 기준입니다. 순위·RP를 직접 늘리거나 능력치를 유료로 강화하는 혜택은 제공하지 않습니다.

최초 달성 장식은 유지하며, 현재 티어 배지는 현재 RP를 따릅니다. 같은 보상을 반복 수령하지 못하도록 서버가 달성 기록을 관리합니다. 포인트성 보상이 추가되더라도 해당 앱 안에서만 지급·사용하며 서로 교환하지 않습니다.

포인트는 각 게임 안에서만

크레딧은 상품 구매에 사용하는 서비스 내 포인트입니다. 현금화·계정 간 양도·선물·외부 거래는 제공하지 않습니다. 유료 상품의 청약철회와 결제 환불 권리는 별도로 보장합니다. 포인트는 앱별로 독립 운영합니다. 현재 퀴즈에는 골드와 크레딧이 함께 있으므로, 즉시 이름만 바꾸거나 잔액을 임의로 합치지 않습니다.

획득

정산된 플레이 보상·출석·미션·최초 승급 보상. 운영 중인 보상은 잔액을 보존하며, 통합 보상표는 적용 전에 공개합니다. 문제 취합 메뉴를 포인트 획득 경로로 다시 만들지 않습니다.

사용

캐릭터 해금·꾸미기·선택형 콘텐츠. 캐릭터 능력의 성장과 숙련도는 구매하지 못합니다. RP·순위 상승을 직접 판매하지 않습니다.

기존 잔액 보호

각 앱의 기존 골드·크레딧과 구매 내역을 그대로 보존합니다. 앱 간 교환·잔액 통합·송금은 제공하지 않습니다. 한 앱의 포인트를 다른 앱에서 결제 수단으로 사용할 수 없습니다.

동물 8종 · 하나의 페르소나

같은 계정의 캐릭터 선택·외형·경험을 이어가는 통합 설계입니다. 퀴즈에서 검증된 성격과 능력 이름을 유지하고, 투자·호텔에서는 해당 게임의 판단을 돕는 방식으로 번역합니다. 뉴스나 힌트는 수익을 보장하지 않습니다.

어느 게임에서도 같은 내 자리

우측 상단에 내 동물 캐릭터, 통합 티어 이름·모양, RP, 통합 순위, 해당 앱의 포인트을 표시합니다. 아직 집계되지 않은 순위는 ‘미집계’로 표시합니다. 결과 화면은 이번 판 성과 → RP 변화와 승급 → 크레딧 보상 → 순위표 순서로 보여줍니다.

크레딧 사용 원칙

잔액과 내역에서 구매한 크레딧과 보상 크레딧을 구분합니다. 구매한 크레딧에 임의의 만료 기한을 두지 않습니다. 포인트 사용처·차감 순서·취소 및 환불 조건은 이용 전에 안내합니다.

현재 통합안의 사용처는 게임 내 캐릭터·꾸미기·콘텐츠입니다. 실제 배송 상품·기프티콘 사용은 아직 제공하지 않으며, 사용처 확정과 별도 결제·법률 검토가 필요합니다. 유료 크레딧의 앱 간 공유는 제공하지 않습니다.
