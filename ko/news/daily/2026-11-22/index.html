AWS Quick, 개인의 작업 절차를 팀의 반복 흐름으로

AWS Blog · 발표 2026-11-20

AWS는 대화로 만드는 Flows와 웹 앱의 지속 작업·다중 에이전트 연결을 소개했습니다.

AWS는 11월 20일 Quick의 업무 흐름·웹 앱·에이전트 협업 기능을 발표했습니다. 대화로 업무를 설명하면 에이전트·스킬·도구를 엮는 흐름을 만들고, 고정 계산·검사 단계를 넣어 반복 실행을 구성할 수 있습니다. 웹 앱은 탭을 닫은 뒤에도 시작한 작업을 이어가며, 여러 전문 에이전트의 결과를 한 응답으로 모읍니다. Meta 광고와 Amplitude 연결도 추가됐습니다. 커넥터는 기존 접근 권한을 따르고 쓰기 작업 전 허락을 받습니다. 프롬프트 보호 기능은 미리보기이며 일부 관리 기능은 Professional·Enterprise 요금제가 대상입니다.

AP의 관점

AP의 콘텐츠·기업 교육 업무에 참고한다면, 가상 월간 보고에서 고정 계산·초안 작성·최종 승인을 분리하는 흐름을 제안합니다. 한 사람이 아는 순서를 다른 구성원도 같은 기준으로 실행하는지 확인하고, 탭을 닫은 뒤의 지속 실행과 결과 검토를 구분할 수 있습니다.

02 / AI NEWS

Textract Insights, 추출한 값에서 원문 위치까지

AWS Blog · 발표 2026-11-20

AWS는 값마다 신뢰도와 페이지·좌표 근거를 돌려주는 문서 처리 기능을 일반 제공한다고 발표했습니다.

AWS는 11월 20일 Textract Insights의 일반 제공을 발표했습니다. 자연어 설명을 담은 JSON Schema로 필요한 필드를 정하고 문서 묶음을 비동기 요청으로 처리합니다. 명시적으로 읽은 값과 내용에서 추론한 값 모두 신뢰도·페이지·좌표 근거를 제공합니다. 입력은 PDF·PNG·JPEG·TIFF이며 영어·프랑스어·독일어·이탈리아어·포르투갈어·스페인어를 지원합니다. 기존 Textract Core의 40개 언어 지원과 같은 범위가 아닙니다. Insights는 도쿄·취리히에 아직 제공되지 않으며 페이지 단위 과금과 지역 내 교차 리전 추론 조건을 확인해야 합니다.

AP의 관점

AP의 문서 교육이나 Lia Select 거래 자료 정리에 참고한다면, 공개 영문 샘플에서 읽은 값·추론 값·원문 위치를 함께 기록하는 과제를 제안합니다. 한국어 문서 지원을 임의로 가정하지 않고, 신뢰도 수치가 높아도 금액·조건을 원문과 대조하는 절차를 설명할 수 있습니다.

03 / AI NEWS

분산 KV 캐시 스킬, 설치보다 먼저 실제 이득 계산

AWS Blog · 발표 2026-11-20

AWS의 새 가이드는 자체 호스팅 LLM의 반복 계산을 줄일 수 있는지 먼저 평가하도록 안내합니다.

AWS는 11월 20일 Agent Toolkit for AWS의 분산 KV 캐싱 스킬을 소개했습니다. 자체 호스팅 LLM이 이전 문맥의 계산 상태를 여러 서버에서 재사용하도록 적합성 평가·비용 추정·설정·문제 해결을 돕습니다. KVTrace는 실제 트래픽의 블록 해시와 토큰 수로 후보 캐시 크기를 비교하며 프롬프트 원문·토큰 ID를 저장하지 않습니다. 다만 민감한 입력의 해시는 익명화 설정을 확인해야 합니다. 짧은 입력이나 이미 높은 로컬 적중률에서는 이득이 작을 수 있고, 절약한 GPU 시간이 실제 비용 절감이 되려면 서버 수 감소나 같은 장비의 처리량 증가로 이어져야 합니다.

AP의 관점

AP의 웹·AI 서비스 설계 교육에 참고한다면, 반복 요청 비율과 첫 응답 시간을 기록한 가상 자료로 재사용의 손익을 비교하는 과제를 제안합니다. 새 인프라를 만들지 않고도 캐시 비용·저장 경계·결과 일치 검사를 먼저 검토할 수 있습니다.

Standard Bank의 AI 위험 평가, 근거 수집과 승인은 분리

AWS Blog · 발표 2026-11-20

고객 사례는 자동 시험과 근거 보고서를 기존 위험위원회의 승인 절차에 연결합니다.

AWS는 11월 20일 Standard Bank Group이 생성형 AI 사용 사례의 위험 평가를 자동화한 구축 사례를 소개했습니다. 사전 평가 에이전트가 코드·문서의 근거를 모으면 담당 팀이 오류와 누락을 검토합니다. 이후 실제 애플리케이션 호출과 자료 검사를 수행하고, Bedrock 모델의 좁은 예·아니요 판단을 고정 산식으로 점수화합니다. 반복 판단이 불일치하면 검토 화면에 표시하고 근거를 보존합니다. 최종 검토·승인은 위험위원회가 맡으며, 이 평가는 규제 준수 인증이 아닙니다. 운영 중 정기 재평가는 실제 작업 연결 뒤의 확장 계획으로 설명합니다.

AP의 관점

AP의 기업 AI 교육·웹 서비스에 참고한다면, 공개 예제의 기준별 근거·실제 출력·미확인 항목을 나눈 점검표를 제안합니다. 자동 평가 점수와 사람의 승인 판단을 구분하고, 기준 자료와 실패 사례를 보존해 변경 전후를 비교할 수 있습니다.

Gemini의 Mac 컴퓨터 사용, 백그라운드 실행과 통제

Google Blog · 발표 2026-11-19

Google은 격리 창에서 로컬 앱·파일·웹을 다루는 기능을 미국 영어 이용자부터 순차 제공합니다.

Google은 11월 19일 Gemini Mac 앱의 컴퓨터 사용 기능을 발표했습니다. 격리된 백그라운드 창에서 클릭·입력·메뉴·양식 작업을 수행하고 채팅의 실시간 미리보기로 확인할 수 있습니다. 이용자는 접근 앱을 선택하고 언제든 일시정지하며 중요한 행동 전 승인을 합니다. 미국에서 영어로 순차 제공하고, Apple Silicon Mac과 macOS Sequoia 15.0 이상이 필요합니다. 18세 이상 개인 Google 계정의 AI Plus·Pro·Ultra 이용자가 대상입니다. 한국의 모든 계정 지원이나 컴퓨터 전원이 꺼진 상태의 실행을 약속하는 발표는 아닙니다.

AP의 관점

AP의 AI 활용 교육과 Lia Select 상품 등록 흐름에 참고한다면, 가상 상품 자료를 양식 초안으로 정리하는 수업안을 제안합니다. 배경 실행과 서버 독립 실행을 구분하고, 실제 판매·발송 전 확인 및 중단 지점을 따로 설명할 수 있습니다.
