AI의 데이터 길목, 공통 관문으로 묶다

AWS · 발표 2026-11-06

AWS는 메타데이터로 데이터셋을 연결하는 MCP 서버 구축 방식을 소개했습니다.

AWS는 Amazon 북미 분류센터 운영 데이터를 AI로 조회하는 MCP 서버 구축 사례를 공개했다. ECS Fargate 위의 공통 관문이 데이터셋 메타데이터와 접근 제어를 모으고, 새 데이터셋은 메타데이터 JSON과 필요한 맥락 설정으로 연결한다. Athena 도구는 SELECT 쿼리만 허용하고 쓰기 작업을 거절한다. 독립된 새 서비스 출시가 아니라 기술 구현 사례다.

AP의 관점

AP가 기업 고객의 자료 조회 기능을 설계한다면, 자료의 의미와 열람 범위를 한곳에서 관리하고 AI의 조회 권한을 쓰기 권한과 분리하는 방식을 검토할 수 있다.

02 / AI NEWS

원격 코딩 작업도 결과는 검토 가능한 변경안으로

AWS · 발표 2026-11-06

AWS의 원격 Claude Code 예제는 격리된 실행과 최종 검토를 나눕니다.

AWS는 Claude Code 작업을 AgentCore의 개별 격리 세션에서 실행하는 예제를 소개했다. 작업별로 저장소를 가져와 코드를 수정하고 저장소의 검증 명령을 실행한 뒤, 결과를 GitHub 풀 리퀘스트로 반환한다. 에이전트는 직접 병합하지 않는다. 프롬프트 사전 검사는 저장소 파일에서 들어오는 간접 지시까지 모두 검사하는 장치는 아니며, 신뢰하는 저장소의 한정된 작업에 적합하다고 설명한다.

AP의 관점

AP의 웹 서비스 변경 절차를 점검한다면, 실행 환경 분리와 별개로 검증 명령·결과·최종 반영 결정을 남기는 기준을 둘 수 있다.

03 / AI NEWS

누가 요청했고 어떤 에이전트가 대신했는가

AWS · 발표 2026-11-06

Okta와 AgentCore를 연결한 예제는 사용자와 에이전트의 권한을 함께 확인합니다.

AWS는 Okta Cross App Access와 AgentCore Identity를 연결해 사용자 대신 일하는 에이전트의 접근을 통제하는 구현 방법을 공개했다. 관리자가 허용한 애플리케이션과 사용자 할당을 확인하고, 짧은 수명의 접근 토큰에 사용자와 에이전트의 정보를 함께 담는다. 개별 도구도 사용자 그룹과 요청 범위를 검사한다. 권한 회수와 이미 발급된 토큰의 만료는 구분해 확인해야 한다.

AP의 관점

AP가 고객 지원 도구에 대리 실행을 연결한다면, 로그인한 사용자 확인에 더해 어떤 자동화가 어떤 자료와 작업에 접근하는지도 함께 점검할 수 있다.

04 / AI NEWS

GPU 한 대를 나눠 쓰되, 비용 계산은 따로

AWS · 발표 2026-11-06

SageMaker 추론의 GPU 분할은 모델에 맞는 자원 크기를 고르게 합니다.

AWS는 SageMaker 실시간 추론의 inference component 엔드포인트에 NVIDIA MIG 기반 GPU 분할을 지원한다고 발표했다. 분할마다 전용 연산·메모리 자원을 배정할 수 있지만, 서버리스 엔드포인트와 혼합 인스턴스 풀에는 적용되지 않는다. 같은 인스턴스의 CPU·네트워크 등은 여전히 공유되며 전체 인스턴스 시간 요금도 그대로다. GPU 분할만으로 완전한 고객별 격리가 되지는 않는다.

AP의 관점

AP가 AI 교육용 서비스나 고객별 모델 운영 구조를 비교한다면, 자원 활용률과 비용 절감 주장을 구분하고 실제 부하·공유 자원·보안 경계를 함께 확인하는 기준을 세울 수 있다.

05 / AI NEWS

반복 보안 알림, 분류와 사람의 판단을 연결하다

AWS · 발표 2026-11-06

Greenlight의 운영 사례는 반복 사건과 복잡한 사건의 처리 경로를 나눕니다.

AWS는 Greenlight Financial의 Luna 보안 운영 시스템 구축 사례를 소개했다. 여러 전문 에이전트를 조정하는 1차 분류와 심층 조사 단계를 나누고, 과거 처리 결과를 기억해 유사 사건을 중복 확인한다. 복잡한 사건은 추가 조사로, 위험도가 높은 사건은 근거를 갖춰 사람에게 이관하는 흐름을 설명한다. 해당 기업의 운영 사례이며 모든 조직의 동일한 성과를 보장하지 않는다.

AP의 관점

AP의 뉴스 발행 점검을 설계한다면, 같은 원인의 반복 알림을 묶는 규칙과 새로운 실패·회복을 알리는 규칙을 구분하고 사람이 판단할 지점을 명확히 둘 수 있다.
