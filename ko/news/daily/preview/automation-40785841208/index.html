01 / CONNECTED APPS

Google, 검색과 Gemini를 잇는 앱 연결 플랫폼 미리보기

Google 공식 블로그 · 발표 2026-10-28

서비스를 AI에 연결하는 통로가 넓어지지만, 공개 심사와 시장별 제공 조건이 남아 있습니다.

Google은 Connected Apps Platform 미리보기를 발표했습니다. 개발자는 클라우드 MCP 서버 또는 AppFunctions 기반 Android MCP로 연결하고 Google Connected Console에서 등록·시험·제출합니다. 심사 전 Search와 Gemini 중 공개 대상을 선택하며, 공개 뒤 트래픽·지연·오류율을 확인할 수 있습니다. 접근 권한과 시장은 단계적으로 확대됩니다. 한국·싱가포르 전체 개발자에게 즉시 개방됐다고 단정할 수 없습니다.

AP의 관점

AP의 웹·서비스 구현은 독립된 홈페이지 제작과 함께 외부 AI가 읽고 실행할 수 있는 서비스 연결 구조를 검토할 수 있습니다. Lia Select의 상품 정보도 국가별 제공 범위와 인증·구매 승인 절차를 확인한 뒤 연결하는 접근이 적합합니다.

02 / WORKFLOW DESIGN

Claude, 출처를 연결하는 법무용 아티팩트 공개

Anthropic 공식 제품 블로그 · 발표 2026-10-28

전문가용 AI가 답변을 넘어 출처와 승인 담당자가 보이는 업무 도구로 발전합니다.

Anthropic은 Claude for Legal에 계약 검토·규제 추적·법무 요청 접수 등에 맞춘 아티팩트 갤러리를 소개했습니다. 문서 인용 검증, 관할별 비교, 계약 조항의 표준 이탈 검토 등을 예시 데이터로 살펴보고 자체 문서와 커넥터에 맞게 조정할 수 있습니다. AI가 초안을 처리하고 변호사가 판단하는 구조를 명시합니다. 한국 법률 적합성이나 모든 계정의 이용 자격이 보장된 발표는 아닙니다.

AP의 관점

AP의 교육·서비스 구현에서도 입력 자료, 결과의 근거, 예외 승인 담당자가 함께 보이는 업무 화면이 중요합니다. 법률 판단을 대신하는 서비스로 확장하기보다 전문가 검토가 필요한 지점을 분명히 하는 설계 사례로 활용할 수 있습니다.

03 / PERSONAL AI

Chrome, Gmail 정보로 자동완성 범위 확대

Google Chrome 공식 블로그 · 발표 2026-10-28

편리한 입력 지원이 늘어날수록 어떤 개인정보에 접근하는지 설명하는 화면이 중요해집니다.

Google은 Chrome의 향상된 자동완성이 Gmail의 주문번호·배송 정보·항공 예약 등을 양식 입력 시 제안한다고 발표했습니다. Personal Intelligence를 켠 Gemini in Chrome 이용자를 대상으로 미국의 데스크톱·Android·iOS에서 순차 제공됩니다. 접근 범위와 활성화 여부는 Chrome 설정에서 관리합니다. 한국이나 싱가포르 출시로 해석할 수 없으며 Google Photos 이미지 접근은 향후 확대 계획입니다.

AP의 관점

Lia Select의 싱가포르 커머스와 AP가 만드는 고객 입력 화면에서도 필요한 정보만 요청하고 자동으로 가져온 값은 제출 전에 확인하게 하는 구성이 유용합니다. 이 기능의 국내 도입 여부와 별개로 동의와 수정 가능성을 설계 기준에 반영할 수 있습니다.

04 / AI FOR SCIENCE

Anthropic, 과학 연구 지원을 기관 협력으로 확대

Anthropic 공식 발표 · 발표 2026-10-28

연구용 AI 지원이 개인 실험에서 기관의 데이터와 공동 도구를 다루는 방향으로 넓어집니다.

Anthropic은 AI for Science 프로그램 확대와 함께 전 세계 재단·기관·연구 그룹 20곳의 협력을 소개했습니다. 영향력이 큰 과학 프로젝트의 연구자에게 Claude 크레딧을 지원하고 공개 데이터·소프트웨어·표준 등 공동 자산을 지향합니다. 실험 장비를 AI 에이전트가 다루도록 하는 Model Hardware Standard는 연구 미리보기 단계입니다. 일반 기업의 무료 이용이나 확정된 연구 성과를 의미하지 않습니다.

AP의 관점

AP의 AI 교육에서도 도구 이용권과 검증된 성과를 구분하고, 재현할 수 있는 자료·절차를 남기는 학습 구성이 필요합니다. 기관별 접근 조건과 데이터 사용 권한을 확인하는 사례로 다루면 단순 기능 소개보다 실무 판단에 도움이 됩니다.

05 / SOFTWARE DELIVERY

GitHub Universe, 코드 생성을 넘어 완성된 서비스 전달 강조

GitHub 공식 블로그 · 발표 2026-10-28

개발 AI의 평가 기준이 생성한 코드의 양에서 검증하고 운영에 전달한 결과로 옮겨갑니다.

GitHub은 Universe 2026에서 Copilot 앱·프로젝트·모델 조정 기능과 자동화·코드 검토의 확장을 발표했습니다. 클라우드 세션을 여러 화면에서 이어가고 자동화 결과를 바탕으로 개선을 제안하는 방향을 설명했습니다. 개발자가 방향과 의사결정을 맡고 결과에 책임지는 구조를 강조합니다. 제품별 이용 조건과 비용은 별도 확인 대상이며 모든 기능이 무료라는 의미는 아닙니다.

AP의 관점

AP의 웹·서비스 구현에서도 개발 속도와 함께 실제 공개 확인, 실패 복구, 담당자에게 전달되는 운영 기록을 결과물에 포함해야 합니다. 콘텐츠·뉴스레터 자동화 역시 생성 성공이 아니라 독자가 볼 수 있는 공개와 발송 접수까지 확인하는 운영 기준이 필요합니다.
