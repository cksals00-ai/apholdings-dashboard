Google, 건강 AI 평가의 세 축 공개

Google · 발표 2026-11-04

정확성·안전성·유용성을 함께 살피는 평가 방법을 공유했습니다.

Google은 건강 분야 AI를 평가하는 백서를 공개했다고 밝혔다. 정확성·안전성·유용성을 평가하며, 정답이 정해진 질문의 벤치마크와 자동 평가, 전문가 검토를 결합한다. 흔한 건강 질문과 위험도가 높은 상황을 함께 다루는 방법론으로, 특정 제품의 임상 효능이나 국내 사용 승인을 뜻하지 않는다.

AP의 관점

AP가 전문 분야 AI 교육을 설계한다면 정답률 외에 위험한 답변과 실제 과제 수행 여부를 별도 항목으로 정하고, 전문가 확인이 필요한 경계를 수업 자료에 표시할 수 있다.

02 / AI NEWS

AWS, 에이전트 맥락 관리를 네 층으로 설명

AWS · 발표 2026-11-04

긴 대화 하나에 모든 정보를 쌓지 않는 구현 가이드입니다.

AWS는 Strands Agents SDK와 Bedrock AgentCore 기반의 오픈소스 Deep Insight 구현을 통해 맥락 관리 방법을 소개했다. 역할별 맥락 분리, 응답량 제어, 파일로 정보 외부화, 독립 검증과 보호 장치의 네 층을 설명한다. 원문의 절감 수치는 해당 참조 구현의 결과로, 모든 서비스의 비용이나 정확도를 보장하지 않는다.

AP의 관점

AP가 뉴스레터나 보고서 제작 흐름을 설계한다면 원문 자료와 계산 결과는 파일에 보존하고, 단계 사이에는 필요한 요약과 위치만 넘기는 방식을 검토할 수 있다.

GitHub, Copilot 사용량에서 자체 모델 구분

GitHub · 발표 2026-11-03

로컬 모델과 기업 맞춤 모델 사용량을 별도로 볼 수 있게 됐습니다.

GitHub는 Copilot 사용량 지표 API에 자체 키·로컬 모델 이용과 기업 맞춤 모델 이용을 구분하는 정보를 추가했다. 로컬 BYOK는 개발자 클라이언트에서 설정하며, 기업 맞춤 모델은 관리자가 설정하고 요청이 GitHub를 거친다. 두 유형은 기업·조직의 사용자별 및 집계 보고서에 나타난다.

AP의 관점

AP가 개발 도구의 사용 현황을 검토한다면 구독에 포함된 요청과 별도 제공사 또는 로컬 실행을 구분해 기록하는 기준을 만들 수 있다.

AWS, 문서와 매출 표를 하나의 대화로 연결

AWS · 발표 2026-11-03

Amazon Quick의 데이터 결합 방법을 소개한 실습입니다.

AWS는 Amazon Quick에서 S3 문서 지식 베이스와 구조화 데이터셋을 Space에 연결하고 대화형 에이전트로 함께 조회하는 방법을 안내했다. 실습에는 Enterprise 구독과 데이터 접근 권한 등이 필요하다. 원문은 공유 대상의 Space·지식 베이스·데이터셋 권한을 각각 확인하고 필요한 자료만 연결하도록 설명한다.

AP의 관점

Lia Select의 상품·매출 표와 운영 문서를 함께 분석하는 구상을 검토한다면, 먼저 열의 의미와 통화·기간 기준을 맞추고 담당자별 문서 접근 범위를 정할 수 있다.

GitHub, 에이전트 지침 패키지의 버전 갱신 지원

GitHub · 발표 2026-11-03

Dependabot이 Agent Package Manager 의존성 업데이트를 지원합니다.

GitHub는 Dependabot이 apm.yml에 선언된 지원 Git 의존성을 갱신하는 변경 요청을 만들고, apm.lock.yaml이 있으면 다시 생성한다고 발표했다. 대상에는 AI 에이전트의 스킬·프롬프트·지침이 포함된다. 이는 버전 업데이트 지원이며 보안 업데이트 지원과는 다르다. github.com의 모든 요금제에서 일반 제공된다.

AP의 관점

AP가 재사용 교육·개발 지침을 패키지로 관리한다면 변경된 지침을 기존 평가 과제와 비교한 뒤 채택하는 검토 절차를 구성할 수 있다. 최신 버전이라는 이유만으로 결과 품질을 가정해서는 안 된다.
