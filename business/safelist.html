해자 — 압도적 신뢰, 그리고 ‘Safe for Me’ 기피 메모리

신뢰의 자산화

아토피·알레르기 가정이 가진 질환 정보는 가장 민감한 데이터입니다. 우리는 단기 광고 수익을 포기한 대신 0 광고 · 0 계정 · 0 서버 · 1 원칙(타협 없는 안전 최우선)으로 사용자의 절대적 신뢰를 확보했습니다. 이 훼손되지 않은 신뢰가 커머스로 확장하는 명분입니다.

개인화 기피 메모리

「우리 아이는 우유·밀·특정 보존제를 피한다」를 한 번 설정하면, 앱 내 검색·온라인 마켓·오프라인 매장 스캔 등 모든 접점에서 그 개인 필터가 자동으로 적용됩니다. 기피 데이터가 쌓일수록 다른 플랫폼으로 옮길 이유가 사라집니다 — 가장 강한 전환 비용입니다.

단, 이 메모리는 기기에 있습니다. 서버 동기화는 사용자가 켤 때만(옵트인), 아이 실명 대신 별칭으로, 암호화해서, 한 번에 지울 수 있게 만듭니다.

코어 테크 — 5단계 스코어링 엔진 & OCR

세이프리스트는 스캐너가 아니라, 이 엔진을 심장으로 온·오프라인 커머스를 돌리는 플랫폼입니다.

원재료 라벨 캡처스마트폰 카메라로 라벨·바코드 실시간 인식
OCR 텍스트 추출비정형 텍스트에서 식약처 고시 기준 성분명 정제
성분 DB 대조16.5만 개 이상의 글로벌·국내 식품·화장품 첨가물 및 알레르기 DB 크로스체크(식약처·환경부 초록누리·EWG·SkinSAFE 기준)
개인 설정 필터링유저별 기피 성분(알레르겐·특정 보존제) 메모리 엔진 대조
스코어 표출 · 대안 추천안전도 점수 및 개인별 경고 라벨, 검증된 대체재 즉시 추천 — 검증된 대안이 없으면 「아직 없어요」라고 말합니다

별칭 사전 2종(식품: 카제인·유청·글루텐 등 / 화장품: INCI↔한글, 착향제 25종)이 성분명의 다른 표기를 같은 성분으로 묶습니다. 모든 판정 끝에는 「진단 아님 · 공개 DB 기준 · 최종 판단은 보호자」를 고정합니다.

사업 모델 — O4O 듀얼 엔진 생태계

중앙 알고리즘을 심장으로 온라인 D2C 안심 마켓(Engine A)과 오프라인 안심 가맹점(Engine B)을 무한 루프로 돌립니다.

ENGINE A · 온라인 D2C 안심 마켓

정보 탐색 앱에서, 완벽히 큐레이션된 제품을 직접 구매하는 폐쇄형·맞춤형 안심 버티컬 커머스로 진화합니다. 상품을 검색해서 찾는 일반 쇼핑몰과 달리, 알고리즘이 유저의 기피 성분을 100% 배제한 안전 상품군만 골라 노출하는 역발상 구조 — 검색이 필요 없는 쇼핑입니다.

혁신적 UX · 자동 마스킹 큐레이션

앱을 켜는 순간 ‘Safe for Me’ 데이터에 위배되는 위험 상품은 시각적으로 마스킹(Blur)되고, 오직 ‘나에게 안전한 제품’만 하이라이트됩니다. 알레르기 환자가 상세 페이지마다 성분표를 확인해야 하는 피로를 0으로 만듭니다. (독자 UI/UX, 특허 출원 계획)

3대 수익 모델

  • 맞춤형 정기 구독 — 질환·연령(예: 아토피 영유아)에 맞춰 매월 안전한 간식·식자재·스킨케어를 알고리즘이 엄선해 발송
  • 세이프리스트 PB — 앱 내 검색 DB 분석으로 수요는 높으나 안전한 대체품이 없는 제품군(특정 첨가물 없는 소스류, 무자극 세제)을 자체 개발
  • 1차 생산자 직송 — 유기농·무농약 인증 생산자 직계약으로 중간 유통 마진 제거 (미국 Thrive Market 벤치마킹)
ENGINE B · 오프라인 안심 가맹점 (O4O)

SafeList Certified Market — 세이프리스트의 성분 기준을 통과한 안전 제품만 독점 취급하는 오프라인 인증 가맹점과 숍인숍(Shop-in-shop) 매장. 온라인의 ‘안심 큐레이션’ 경험을 물리적 공간으로 확장합니다. 고객은 눈으로 보고 만지며, 앱과 연동된 스마트 쇼핑을 합니다.

입지 선점

소아과 인근, 영유아 밀집 아파트 단지, 프리미엄 상권 등 건강 관여도가 높은 지역부터 랜드마크화. 여기에 한국관광 데이터랩의 외국인 카드 소비·이동통신 방문자 데이터로 외국인 소비가 큰 상권(명동·홍대·성수 등)을 겹쳐, 인바운드 안심 소비 거점을 동시에 잡습니다.

플라이휠 — ① 온라인 큐레이션 경험이 오프라인 방문과 브랜드 신뢰를 유도 → ② 매장 스마트 스캔이 실결제·행동 데이터를 축적 → ③ 중앙 엔진이 정기 구독과 큐레이션을 정교화 → ④ 고도화된 핀셋 수요가 PB 개발과 가맹점 확장을 견인. 온·오프라인의 경계가 허물어지고, 고객은 ‘안전한 삶’을 위해 세이프리스트 생태계에 머뭅니다.

가맹점이 지키는 것은 하나입니다 — 안심 기준을 통과한 상품만 둡니다. 점수는 특정 브랜드의 광고로 조작되지 않으며, 오직 알고리즘과 공개 DB에 근거합니다.

AI 커넥터 — 세이프리스트 데이터 오라클

커머스는 검색(Web) → 추천(App) → 자율 쇼핑(Agentic Commerce)으로 갑니다. 사용자의 명령 한 번으로 AI 에이전트가 탐색·검증·결제·배송을 백그라운드에서 끝내는 시대에, 세이프리스트는 이 M2M 시장의 데이터 노드가 됩니다.

AI의 한계

건강과 생명이 직결된 아토피·만성질환자의 성분 검증을 범용 LLM의 확률적 생성(환각)에 맡길 수 없습니다.

세이프리스트의 답 — 그라운드 트루스

범용 AI가 성분의 안전성을 신뢰하고 쿼리할 수 있는 검증 인프라(Data Oracle)로 포지셔닝합니다. AI는 이 기준을 통과한 데이터만으로 자율 쇼핑을 수행합니다.

글로벌 표준 연동 아키텍처

MCP(Model Context Protocol)와 표준 API로 Anthropic(Claude) → OpenAI(GPT) → Google(Gemini) → Apple(Siri·스마트 기기)에 연동합니다. 목표는 전 세계 AI 디바이스에 ‘기본 건강 성분 검증 모듈’로 탑재되는 것입니다. 첫 구현은 무상태 MCP 서버, 도구 4개입니다.

도구하는 일
lookup_product바코드·제품명 → 원재료 표 (식약처 공개 DB)
check_ingredients원재료 + 피할 성분(별칭) → 안전/주의/피함 판정 + 근거
explain_ingredient성분 하나의 다른 이름·어디에 들어가는지 설명
find_alternatives검증된 안심 대안 카탈로그(식품·화장품·생활화학) → 제휴 링크 → D2C

제로 프릭션 시나리오

음성 명령“Siri야, 우리 아이 아토피에 안전한 유기농 간식 1주일 치 주문해 줘.”
AI의 검증 요청에이전트가 백그라운드에서 SafeList API 호출
오라클 응답유해 성분 0%인 최적 대체 상품 리스트 반환
자율 결제확인 화면 없이 D2C 망으로 결제·배송 지시 완결

불변 원칙: 서버는 「성분표 + 피할 성분」만 받고 응답 후 버립니다. 사진·기록·리포트는 기기에만. 미래 M2M 수익은 외부 AI 에이전트·서드파티가 오라클을 쿼리할 때마다 과금하는 SaaS형 API 호출 수익입니다.

인바운드 연결 — 외국인의 안심 소비, 데이터랩으로 자리를 잡습니다

2026년 1~7월 방한 외래객 1,280만 명(+21.3%), 1인당 지출 약 $1,008. 그 돈의 큰 몫이 식음료와 쇼핑입니다. 알레르기·성분 정보는 외국인에게 언어 장벽이 가장 높은 영역이고, 그래서 세이프리스트가 가장 잘하는 자리입니다.

외국인용 판정

원재료 표는 한국어, 판정은 사용자 언어로. 국적별 입국 순서(중국·일본·대만·미국)대로 언어를 붙입니다. K-Scan(베트남)과 한 엔진을 씁니다.

안심 가맹점 = 외국인 소비 거점

데이터랩의 신용카드 외국인 소비(업종·지역)와 이동통신 방문자로 외국인이 실제로 쓰는 상권을 찾고, 그곳의 약국·편의점·유기농 매장에 숍인숍 안심 코너를 먼저 둡니다.

귀국 후 재구매

한국에서 스캔해 ⚪로 확인한 제품을 귀국 후 D2C·파트너 몰에서 다시 삽니다. 관광 소비가 수출로 이어지는 마지막 단계입니다.

근거 수치: 한국관광공사 관광통계(2026-08-25 공표), 현대경제연구원(2025-06). 상세는 홈 · 데이터랩 섹션.
