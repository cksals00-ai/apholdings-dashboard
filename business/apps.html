관리대장·현장 점검·체크리스트·사진과 문서 등록·만료일 안내처럼 반복하는 업무에 맞춥니다. 고객이 별도 서버를 개설하거나 직접 관리할 필요 없이 AP가 운영합니다.

  1. 업무 파악·견적

    현재 엑셀과 업무 순서를 보고 꼭 필요한 화면과 기능, 비용을 확정합니다.

  2. 업무 앱 제작

    직원이 휴대폰에서 등록·조회하고 업무를 이어갈 화면을 만듭니다.

  3. 사용자 가이드

    실제 화면과 버튼 순서, 성공 확인과 오류 대처까지 설명합니다.

  4. 관리자 화면·가이드

    권한이 있는 담당자가 설정을 바꾸고 운영하는 방법을 제공합니다.

  5. 테스트 운영

    가상 자료로 사용 흐름을 확인하고 합의한 검수 기준으로 점검합니다.

  6. 수정 요청·이력 관리

    접수부터 검토·수정·확인까지 남기고 AP가 서버를 관리합니다.

필요한 제공 항목을 선택하고, 앱·가이드·관리자·운영비를 견적서에 각각 표시합니다.

서버와 소스코드는 누구 소유인가요?

AP 공통 소스·서버·운영 시스템은 AP 소유이며 계약 범위의 사용권을 제공합니다. 기본 가격에 소스 전체 양도·독립 서버 이전·영구 사용권은 포함하지 않습니다. 별도 이전·소스 인수는 가능 여부와 비용을 협의합니다.

우리 회사 데이터는 어떻게 되나요?

고객 업무 데이터는 고객 소유입니다. 고객사별 접근을 구분하고 동의 없이 다른 회사나 포트폴리오에 공개하지 않습니다. 종료 시 합의한 표준 형식의 데이터·첨부 내보내기를 제공하며 기한·형식·보관/삭제·추가 이관 비용을 계약에 명시합니다.

결제와 무상 수정 기준은 무엇인가요?

착수 50%, 합의한 검수 완료 후 50%이며 세금계산서를 발행합니다. 패키지별 1~3개월은 납품 범위의 재현 가능한 오류 수정 기간입니다. 월 서버 운영료는 개통일부터 별도이며 기능 추가·업무 변경은 사전 견적을 드립니다.

스토어 계정과 운영 한도는 어떻게 정하나요?

공개 스토어·사내 배포의 자격과 심사 요건에 따라 배포 계정·등록 비용을 견적에 명시합니다. AP 서버 이용이 모든 앱의 AP 스토어 계정 배포를 의미하지는 않습니다. 사용량·백업·복구·해지 조건도 계약 전에 확정합니다.
