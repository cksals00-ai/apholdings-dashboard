나의 첫투자 (AP Moonshot) — 개인정보 처리방침

시행일: 2026년 10월 29일

문샷(이하 "앱")은 A.P Holdings가 만든 모의투자 시뮬레이터입니다. 학습·가상 투자 기록은 기기에만 저장하고, 공개 시세 파일 갱신에 네트워크를 사용합니다.

요약

온라인 계정, 분석 SDK, 광고 SDK가 없습니다. 공개 파일 다운로드 시 호스팅 제공자가 접속 IP를 보안 목적으로 기록합니다. 실제 주문·결제·증권사 연동 기능이 없으며, 모든 거래는 가상입니다.

네트워크 사용에 대하여 (정직하게)

앱은 하루 한 번 갱신되는 시세 파일(전일 종가) 하나를 내려받기 위해서만 네트워크에 접근합니다. 공개 파일은 GitHub Pages에서 제공됩니다. 접속 IP와 요청 경로가 호스팅 제공자에게 전달되며 GitHub는 보안 목적으로 IP를 기록·보관합니다. 저희는 개별 IP 로그를 제공받지 않고 위치 추정이나 맞춤 광고에 사용하지 않습니다. 내려받기에 실패해도 앱은 내장된 시세로 정상 동작합니다.

앱이 저장하는 것

학습 진행, 가상 포트폴리오·거래 기록, 보호자 설정·메모와 암호화한 PIN은 사용자의 기기 안에만 저장되며, 앱을 삭제하면 함께 삭제됩니다. 어디로도 전송되지 않습니다.

제3자 서비스

계정·광고·분석·앱 내 결제 SDK가 없습니다. 공개 시세 호스팅에는 GitHub 개인정보 처리방침이 적용됩니다. 호스팅 보안 로그는 GitHub 방침에 따라 보관되며 저희가 개별 로그를 식별·삭제할 수 없습니다. 해당 로그 관련 요청은 GitHub 방침의 문의 절차를 이용할 수 있습니다. 기기 내 기록은 앱의 초기화 기능 또는 앱 삭제로 지울 수 있습니다.

투자 관련 고지

본 앱은 모의투자 시뮬레이터이며 투자 권유·자문이 아닙니다. 시세는 전일 종가 기준이며 실시간이 아닙니다.

Privacy Policy (English)

Effective date: October 29, 2026

Moonshot (AP Moonshot) is a virtual stock-trading simulator by A.P Holdings, with on-device learning and virtual trading records.

The short version

There are no online accounts, analytics SDKs or advertising SDKs. Personal learning and trading records remain on your device. The public-file host records connection IP addresses for security. The app has no real trading, payment, or brokerage features — every trade is simulated.

About network use

The app accesses the network only to download a single daily price file (previous-day closing prices). The public file is hosted on GitHub Pages. The request discloses the network IP and file path to GitHub, which logs and stores IP addresses for security. We do not receive individual hosting IP logs or use them for location inference or advertising. If the download fails, the app works fully from its bundled data.

What the app stores

Your learning progress, virtual portfolio and trade history, parent settings and notes, and encrypted local PIN are stored only on your device and are deleted with the app. They are never uploaded anywhere.

Hosting and deletion

GitHub retains hosting security logs under its Privacy Statement. We cannot identify or delete individual hosting logs. Requests about them may be made through that policy. Local data can be deleted using the reset function or by deleting the app. There are no in-app purchases or subscriptions.

Disclaimer

This app is a simulator and is not investment advice or a solicitation. Prices are end-of-day, not real time.
